There is no registration required, just login using the IDP. Once you login with your account you will be redirected to the user profile page where you need to fill in any missing information. There you enter your Telegram name, select the crittertypes you want to join and decide whether you want to receive email notifications.

!!! warning "Attention"
    It may happen that no `critter types` are displayed for joining. You can still complete the registration in this case.
    In this case, please contact a Critter System Admin afterwards.
